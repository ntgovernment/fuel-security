# Update Docs Prompt

## Purpose
Update all documentation and Copilot instructions in the project to be comprehensive, clear, and helpful for both human developers and coding agents. Ensure that:
- All README and documentation files are up to date.
- Copilot instructions (if present) are explicit and actionable.
- Any onboarding or usage instructions are clear for new contributors.

## Steps
1. Review all documentation files (README, docs/, etc.) and Copilot instruction files.
2. Update or add missing information, focusing on clarity and completeness.
3. Ensure instructions are actionable for both humans and coding agents.
4. Save and commit changes.

---

*This prompt is intended for use by Copilot or other automation agents to keep documentation helpful and current.*
